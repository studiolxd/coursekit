===== coursekit
usage: coursekit [-h] [--version] <command> ...

AI-assisted e-learning course production.

positional arguments:
  <command>
    help        show this help
    init        create a project, or refresh the files coursekit generated in it
    config      show the effective configuration and where each value is set
    rules       production rules in force for a course, and where each value is set
    agents      generate skills, commands and agent settings for Claude Code, opencode and Codex
    uninstall   remove what coursekit setup installed outside the projects (run it before uninstalling the package)
    new         create a course from its title and hours
    import      import courses from eXeLearning packages (.elp): a folder is a course, or a folder of many courses
    videos      videos on forbidden sites that come from an official channel: check, propose, approve or reject
    handoff     the whole process of a course by itself (it signs as Coursekit Handoff, with no client review): title
                and hours, or the code of one that stopped half way
    status      state of every course, or the detail and next step of one
    sync        write units and sections from the approved design (design/matrix.json)
    design      check the local design (design/design.yaml) and export matrix.json, validation.json and the Excel
    outline     compact map of a course, or the text of one section
    paths       every path of the simulations of a course, with its flowchart, in reviews/unit-NN-paths.md (for the
                review)
    preview     play the units of an html course with a simulated LMS: it keeps the progress in the browser and shows
                the SCORM tracking live
    verify      check the content against the production rules
    reviewed    mark a unit as reviewed: by the AI (used by the review agent) or, with --by, by a person
    approve     sign off the design or a unit (people only, never an agent)
    write       write units with the writer agent (WRITER_AGENT / WRITER_MODEL)
    review      AI review of units with the reviewer agent (REVIEWER_AGENT / REVIEWER_MODEL)
    run         launch a command (/new-course, /assemble…) with the agent of its role
    assemble    assemble a unit: plan, diff and record in creator, or build its package with the html backend
    directives  compare the directive registry with the creator catalog
    media       media manifest of a course and how to produce each asset
    video       videos as data (a montage of scenes in the theme of the course): create, check, voice, preview, render
                and catalog
    capture     real captures of an application that coursekit makes with permission: log in, profiles, give or take
                back the permission
    download    download an https address to a file of the project (e.g. the Excel of the design that slxd exports)
    voice       voice providers available here, the voice of the project and the one voice of a course
    tts         voice-over of a script with the course voice
    brand       brand material (Storybook, brand book, websites): converts it for the agents, takes out fonts, logos
                and tokens
    tts-batch   batch of the Gemini voice: see the queue, send it, its state and collect the narrations
    subtitles   captions (VTT) aligning a script with its audio
    delivery    record a delivered SCORM package, print its expected file name or check that it can be delivered
                (check)
    hold        put a course on hold (people only)
    resume      resume a course on hold in the status it had
    client      review of the course by the client: round, changes, approval (people only)
    publish     mirror the courses to the shared folder and write the catalog
    catalog     write the tracking Excel of every course
    theme       design tokens of the theme (of the project or of a course): derive them from the platform, tokens.css
                and the contrast
    setup       prepare this machine for the project (identity, .env, hooks, agents, network)
    doctor      what is installed and configured here for the project
    roles       tool and model of each role
    brief       convert the reference material of a course (or of the project) for the agents
    research    official sources for a course with the search API of the .env (RESEARCH_PROVIDER): it only proposes
                addresses

options:
  -h, --help    show this help message and exit
  --version     show program's version number and exit

===== coursekit assemble
usage: coursekit assemble [-h] [--unit UNIT] [--version VERSION] [--no-check] [--browser BROWSER] [--lesson LESSON]
                          [--lesson-id LESSON_ID] [--brick-ids BRICK_IDS] [--brick-ids-file BRICK_IDS_FILE]
                          [--keep-ids] [--replace-id REPLACE_ID] [--content] [--content-id CONTENT_ID]
                          [--preview PREVIEW] [--review REVIEW]
                          {plan,diff,applied,checked,link,build,check} code

positional arguments:
  {plan,diff,applied,checked,link,build,check}
                        plan, diff, applied, checked and link are for the creator backend; build builds the package of
                        the html backend and check plays it in a browser
  code

options:
  -h, --help            show this help message and exit
  --unit UNIT           unit number (build without it: every unit)
  --version VERSION     build: version of the package; with it the zip is also created in delivery/, if it passes the
                        check
  --no-check            build --version: write the zip without playing it first (check)
  --browser BROWSER     build and check: the browser it is played with (path to the executable; by default the
                        installed Chrome or Edge)
  --lesson LESSON
  --lesson-id LESSON_ID
  --brick-ids BRICK_IDS
  --brick-ids-file BRICK_IDS_FILE
                        applied: file with the brick ids (separated by commas, spaces or lines), when the list is too
                        long for the command line
  --keep-ids            applied: keep the brick ids already recorded for the lesson (for when bricks were only updated
                        with update_brick)
  --replace-id REPLACE_ID
                        applied: with --keep-ids, swaps the id of a brick that was deleted and added again:
                        OLD_ID=NEW_ID, separated by commas
  --content             applied: record the content title as renamed
  --content-id CONTENT_ID
  --preview PREVIEW     link: preview link of the unit
  --review REVIEW       link: review link (client comments) of the unit

===== coursekit capture
usage: coursekit capture [-h] [--mode {browser,desktop,terminal,all}] [--profile PROFILE] [--window WINDOW]
                         [--minutes MINUTES] [--file FILE] [--note NOTE] [--mask MASK] [--prepare PREPARE]
                         [--part PART]
                         {login,logout,profiles,allow,revoke,redact,review,approve,reject,serve,replay,stage} [target]
                         [ids ...]

positional arguments:
  {login,logout,profiles,allow,revoke,redact,review,approve,reject,serve,replay,stage}
  target                login/logout: the profile; the other actions: the code of the course (allow and revoke without
                        it: the permission of the whole project)
  ids                   allow: the resources that may be captured (default: every one that shows an interface);
                        redact, review, approve, reject, replay: the resource; stage: the stage

options:
  -h, --help            show this help message and exit
  --mode {browser,desktop,terminal,all}
                        allow: browser (a web application), desktop (a window of a program), terminal (a shell of its
                        own in a stage) or all (every one of capture.yaml › modes); it can be repeated
  --profile PROFILE     allow --mode browser: the profile of capture.yaml it opens with
  --window WINDOW       allow --mode desktop: the name of the only window that may be captured and driven
  --minutes MINUTES     allow: how many minutes the permission lasts; 0, until it is revoked (default capture.yaml ›
                        grant_minutes)
  --file FILE           redact: the recording or the capture the person provided (default media/recordings/<id>.*)
  --note NOTE           reject: what was left to cover or what is wrong
  --mask MASK           reject: a text to always cover in this resource (can be repeated)
  --prepare PREPARE     stage: one more command run in the stage after its setup (can be repeated)
  --part PART           replay: the part of a recording made in several (a terminal and a browser): its files are
                        <id>-<part>.*

===== coursekit handoff
usage: coursekit handoff [-h] [--code CODE] [--no-intro] [--no-summary] [--notes NOTES]
                         [--approach {expository,decision-based}] [--rounds ROUNDS] [--no-pause] [--new-version]
                         target [hours]

positional arguments:
  target                title of a new course (with its hours) or the code of a course to carry on

  --no-intro            units without the opening introduction section
  --no-summary          units without the closing summary section
  --notes NOTES         extra instructions for the instructional design
  --approach {expository,decision-based}
                        approach of the course: expository (explain, then practise) or decision-based (every section
                        opens with a simulation); default: rules › defaults.approach
  --rounds ROUNDS       attempts per step before it stops (default: rules › handoff › rounds)
  --no-pause            do not wait for the reference material after creating the course folders (without a terminal
                        it never waits)
  --new-version         reopen a delivered course whose content was edited and take it to the next version

===== coursekit media
usage: coursekit media [-h] [--url URL] [--content-type CONTENT_TYPE] [--method METHOD] [--status STATUS]
                       [--recipe RECIPE] [--asset-path ASSET_PATH] [--file FILE] [--alt ALT] [--transcript TRANSCRIPT]
                       [--subtitles-path SUBTITLES_PATH] [--made-with MADE_WITH] [--download DOWNLOAD]
                       [--download-title DOWNLOAD_TITLE] [--download-asset-path DOWNLOAD_ASSET_PATH]
                       [--depicts {interface,concept}] [--decorative | --no-decorative] [--unit UNIT]
                       [--set POINT=X,Y] [--force] [--all] [--clean] [--recapture] [--size SIZE] [--fix]
                       [--frames FRAMES] [--batch] [--find FIND] [--take TAKE] [--color COLOR] [--serve] [--port PORT]
                       [--no-open]
                       {extract,plan,providers,set,upload,redo,embed,fit,render,narrate,optimize,adopt,check,sheet,transcript,stock,anchors,gallery}
                       [code] [id] [more ...]

positional arguments:
  {extract,plan,providers,set,upload,redo,embed,fit,render,narrate,optimize,adopt,check,sheet,transcript,stock,anchors,gallery}
  code
  id
  more                  redo: more assets to redo

options:
  -h, --help            show this help message and exit
  --url URL             upload: upload address (uploadUrl) the platform gave
  --content-type CONTENT_TYPE
                        upload: MIME type of the file, the one the upload was requested with
  --method METHOD       upload: HTTP method (default PUT)
  --status STATUS
  --recipe RECIPE
  --asset-path ASSET_PATH
  --file FILE
  --alt ALT
  --transcript TRANSCRIPT
  --subtitles-path SUBTITLES_PATH
  --made-with MADE_WITH
  --download DOWNLOAD
  --download-title DOWNLOAD_TITLE
  --download-asset-path DOWNLOAD_ASSET_PATH
  --depicts {interface,concept}
                        set: what the resource shows (interface: the interface of a real application; concept: an
                        idea, a diagram, a scene)
  --decorative, --no-decorative
                        set: a decorative image or illustration (it gives no information the text does not): no
                        alternative text and no caption; --no-decorative removes it
  --unit UNIT           set: with --asset-path, the path of the asset in the content of that unit (a portrait the
                        dialogues of several units show: creator takes an image only from its own content)
  --set POINT=X,Y       anchors: write the position of a point in the content and draw the crosshairs again
                        («<point>=x,y», in %; repeatable)
  --force               set: mark the asset even if the theme tokens do not come from the platform
  --all                 redo: redo every asset that uses the theme, not only those made with other tokens
  --clean               redo: also forget the file, the alt text, the transcript, the captions and the tool of the
                        asset (the files stay on disk)
  --recapture           redo: a resource that shows a real interface also forgets its capture, its recordings leave
                        media/recordings/ (kept in .cache/capture/) and it is recorded again (with a permission, by
                        the media agent)
  --size SIZE           fit (required) and render: size WIDTHxHEIGHT, e.g. 1920x1080
  --fix                 check: bring to their loudness the audios and videos that do not have it
  --frames FRAMES       sheet: how many frames the contact sheet has (default media › checks › sheet_frames)
  --batch               narrate: put the scenes in the Gemini batch queue instead of voicing them
  --find FIND           stock: search the illustration sources of the brand (in English)
  --take TAKE           stock: take this illustration (its id) as the SVG of the asset, recoloured to the brand
  --color COLOR         stock: filter by colour (default media › stock › color: black, the line versions)
  --serve               gallery: the gallery in the browser, which updates by itself when the course changes (a local
                        server until Ctrl+C)
  --port PORT           port of the resource gallery (default 8767; if it is taken, a free one)
  --no-open             do not open the browser
